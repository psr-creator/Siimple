# Start here: one seller + AI team

Full guide (job description, agent job cards, routine): https://claude.ai/artifact/D1yNMaHhxtGXbe3aRYd5jH

## One-time setup (about 1 hour)
1. Open Claude Code on this repo (branch `claude/stoic-wright-aq7jpp`). The agents load automatically.
2. `Help me fill the [FILL] items in the sales playbook. Ask me one at a time.`
3. `Use deal-coach on my current pipeline and tell me which 5 deals to push this week: [paste]`
4. Agree service levels: Presales demo ≤10 working days, estimate ≤5 working days; Sales Head discount answer ≤24h, joins deals > AED 150K.
5. `/sdr-daily trading Sharjah 5`

## Daily
| Time | Type |
|---|---|
| 8:30 | `/sdr-daily` |
| 9:30–11:30 | Call block (no AI, no inbox) |
| Before each meeting | `Use discovery-coach: prep [company]` |
| After a demo | `Use solution-architect on these notes: …` then `Use proposal-builder …` |
| Pushback | `Use objection-handler: they said …` |
| 17:00 | `log today: [outcomes]` |
| Friday | `Use deal-coach on my pipeline: [paste]` |

Hard rule: no Lusha credits without your explicit permission (see playbook section 7).
